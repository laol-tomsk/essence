1. Установить всё необходимое (версия, использованная при написании инструкции, *в скобках*):
    * Git *(2.55.0.3)*
    * Docker *(4.85.0)*
    * Go *(1.26.5)*
    * Python *(3.14.7)*

2. Выполнить `docker_compose build` и `docker-compose up -d` в `redmine`

3. Выполнить `docker-compose up -d` в `neo4j`

4. Открыть Redmine по адресу `http://localhost:12000` и войти в него под учёткой `admin` — `admin`. После входа сменить пароль и каким-нибудь способом запомнить его.

5. Открыть в Redmine меню загрузки метода: Method Definitions -> New method definition.

6. Загрузить любой метод под любым названием (при написании инструкции был загружен метод, лежащий в файле `essence/Database manager/prectice/Good_Method.json`). После успешной загрузки ID метода появится в адресной строке после последнего `/`.

7. Открыть Neo4j Browser по адресу `http://localhost:7474` и подключиться к Neo4j с URL `neo4j://localhost:7687`, username `neo4j` и паролем `super_admin`.

8. Выполнить `python main.py` в `Database manager`. Последовательно установить все зависимости, на отсутствие которых он будет ругаться, с помощью `pip install N`, где N - имя пакета, на который он жалуется. (При написании инструкции это были `eel py2neo openpyxl easygui`.)

9. После успешного запуска Database manager создать базу данных из prectice:
    - Нажать Создать базу из prectice
    - Выбрать тот же файл метода, что при загрузке в Redmine (окно выбора файла откроется по нажатию кнопки, но будет зарыто под другими окнами)
    - Перейти в консоль и указать название базы данных `precticeN`, где N — идентификатор метода в Redmine.
    - Дождаться окончания спама в консоли.
    - Закрыть Database manager.

10. Выполнить `go run .` в `essence-api`. 

11. Создать проект в Redmine, включив для него модуль Semat essence.

12. Перейти в проект и на вкладке Essence Method выбрать метод, загруженный ранее. После этого нажать Save current state as iteration.

13. Готово! Теперь на вкладке Iterations можно вызывать функции расчёта, реализованные ранее.

**Важно**: после работы рекомендуется вручную останавливать контейнер Neo4j. Если он будет остановлен аварийно, его перезапуск может представлять значительную сложность.
