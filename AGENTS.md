2. Основы проекта

Redmine-Essence - это научно-исследовательский прототип системы поддержки принятия решений на основе стандарта OMG Essence, выполненный в качестве плагина к Redmine. Он использует байесовские сети, чтобы обнаруживать ложно-положительные ошибки в восприятии проекта менеджером, а также помогать с планированием итерации.

3. Архитектура

Проект состоит из пяти основных частей:
- Alpha. Десктопное приложение на C# / WinForms для описания методов и практик OMG Essence с учётом всех дополнительных данных, которые нужны для работы прототип.
- Database manager. Десктопное приложение на Python с открываемым в недобраузере GUI, которое строит байесовские сети в Neo4j на основе описаний, созданных в Alpha, а также управляет ранее созданными БД.
- Neo4j. Графовая БД, используемая для хранения байесовской сети.
- Essence API. Серверное приложение на языке Go с REST API, реализующее основные функции прототипа и включающее алгоритм прямого вероятностного вывода в байесовской сети, а также разные обёртки над ним (поиск ложноположительных ошибок, планирование итерации, оценка плана итерации и т.п.)
- Redmine. Репозиторий с плагином для системы управления проектами Redmine, написанным на Ruby. Использует базу данных MySQL, в том числе, с дополнительными таблицами от плагина.

Приложение не рассчитано на серверное развёртывание и пока предполагается к локальному запуску. Alpha, Database manager и Essence API запускаются непосредственно на хосте, а Neo4j и Redmine - в Docker.

4. Стиль кода

Не прослеживается. Нет никаких общих конвенций и установок. Но следует писать максимально простой и понятный код - когнитивной сложности в проекте и так хватает. Комментарии должны быть на русском языке.
